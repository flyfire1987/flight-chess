# 参考图棋盘几何实测（经典四色木质飞行棋）

> 实测日期：2026-11-11
> 素材：`docs/ref/board_crop.png`（由用户上传的木质棋盘照片裁切）
> 方法：白色连通域检测圆孔 + HSV 色相环带中位采样（抗阴影）+ DFS 哈密顿环求解
> 所有数字均为像素实测，非目测推测。

## 1. 网格

| 项 | 实测值 |
|---|---|
| 逻辑网格 | **17 × 17** |
| 格距 pitch | **55.2 px** |
| 网格线 x 起点 | 43.0 px |
| 网格线 y 起点 | 44.0 px |
| 白圆孔总数 | **76** |
| ├ 环形跑道 | **52** |
| └ 十字臂道 | **24**（4 条 × 6 格） |
| 中心格 (8,8) | 蓝色底，白字「终点」，无圆孔 |

## 2. 环形跑道（52 格）

- 每色恰好 **13 格**，四色均分。
- 沿环顺时针颜色序列实测为 **G-Y-B-R 严格四色周期**（连续 13 次无例外），
  说明参考图的同色格在环上是等距排布的 —— 这正是规则 5a「跳到前方下一个同色格」的几何基础。
- 角部为 **V 形绕行**（每个角比直角多 2 格），不是简单的直角拐弯。

## 3. 四条终点臂道（每条 6 格，十字汇聚中心）

| 方向 | 颜色 |
|---|---|
| 北（上臂，col 8，row 2–7） | **蓝** |
| 东（右臂，row 8，col 9–14） | **红** |
| 南（下臂，col 8，row 9–14） | **绿** |
| 西（左臂，row 8，col 2–7） | **黄** |

每格中心有白色圆孔；臂道格**不参与**同色跳跃。

## 4. 四象限配色

| 象限 | 主色 |
|---|---|
| 左上 | **黄** |
| 右上 | **蓝** |
| 左下 | **绿** |
| 右下 | **红** |

每个象限含：L 形彩色机场道 + 2×2 白色停机坪（内含 4 个白色圆点 = 4 架待起飞飞机）。

## 5. 与当前部署版（board.json v2）的差异

当前部署版用 **15×15** 逻辑网格（角块 3×3：L 形 5 格机场 + 2×2 停机坪），
52 格跑道同样每色 13 格、同样四色周期跳跃 —— **玩法拓扑一致**，
但**颜色→象限的落位与参考图相差一个旋转**：

| | 左上 | 右上 | 左下 | 右下 |
|---|---|---|---|---|
| 参考图 | 黄 | 蓝 | 绿 | 红 |
| 当前部署 | 绿 | 红 | 蓝 | 黄 |

> 是否按参考图重排颜色落位，需用户确认后执行（属视觉调整，不影响规则正确性）。

## 6. 复现方式

```bash
python3 - <<'PY'
from PIL import Image
import numpy as np
from collections import deque
im = Image.open('docs/ref/board_crop.png').convert('RGB')
a = np.asarray(im).astype(np.float64)
mx, mn = a.max(axis=2), a.min(axis=2)
WHITE = (mn > 160) & ((mx - mn) < 60)   # 白圆孔
GX, GY, P = 43.0, 44.0, 55.2             # 网格原点与格距
# 连通域 -> 圆孔中心 -> 映射到 (row, col)
PY
```
